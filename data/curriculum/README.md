# Curriculum data

Populated once a category is confirmed and migrated out of the draft
Markdown-table files (in the project working folder, e.g.
`25_Levels_and_MiniThemes_Draft.md`) into individual book records — one
`.md` file per book, YAML frontmatter + review body. See `30_Data_Schema.md`
in the project working folder for the full field reference and an example
record.

Folders below are one per category (plus `novels/`), empty until that
category is locked and migrated.
